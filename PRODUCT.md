# Product

**Unified Workstation** turns the computers one person uses into one coordinated workspace:
the same work folder everywhere, one keyboard and mouse across screens, and servers that have
names instead of addresses.

- **Register:** product UI (the design serves the task).
- **Who uses it:** a person who works on two or more computers — a developer, a researcher, a
  student with a laptop and a desktop. Technical skill varies; nobody should need to know what
  Syncthing, Deskflow, systemd or SSH configuration are.
- **The one question the window answers:** *Am I ready to work?* — in about three seconds.
- **Voice:** calm, exact, never alarming. Says what happened, why, and what can be done. No
  jargon outside “Advanced”, no exclamation marks, no blame.
- **Principles:** trust before features; nothing happens to the user's files or system that was
  not explained first; every state is a symbol plus a word, never colour alone; optional things
  stay optional; honest about what an operating system can not do.
- **Anti-references:** an admin console full of toggles; a marketing dashboard with big numbers;
  a terminal skin; anything that looks like it wants attention.
