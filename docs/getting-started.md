# Getting started

Unified Workstation makes the computers you use behave like one workspace.

- **One work folder.** Whatever you put in it is the same on every computer you pair.
- **One keyboard and mouse.** Move the pointer off the edge of one screen and it continues on
  the next computer.
- **Servers with names.** *Home* and *Cloud* instead of addresses you have to remember.

There is no account and no service in the middle: your computers talk to each other directly.

## The five-minute path

1. [Install](installation.md) the application on your first computer and open it.
2. The first-run assistant asks how you use this computer:
   - **Personal computer** — a normal desktop. The application stays out of the way.
   - **Workstation** — sync, shared keyboard and mouse, optional servers.
3. Choose your work folder (the default is `Desktop/Work`).
4. Install the application on your second computer and [pair](workstations.md) the two with a
   code and a six-digit confirmation number.
5. Done. Files appear on both; the overview page says **Ready to work**.

## Two modes, nothing else

- **Default Mode** is your normal desktop. Nothing is rearranged, launched or captured.
- **Workstation Mode** opens your tools — editor, terminal, browser — in one step.

Sync, pairing and servers work the same in both.

## What you never need to do

Edit a configuration file, type an IP address into a file, write a service definition, or
learn how Syncthing, Deskflow, Tailscale or SSH configuration work. Everything is in
**Settings**. A command line exists for people who want one: see [Advanced](advanced/README.md).
